# BlueMax ERP

**نظام إدارة مصنعي (ERP) لتشغيل المصانع من سطح المكتب — بواجهة عربية كاملة.**

A Windows desktop ERP system built for factory operations, with a dedicated server component, maintenance tools, and an Arabic-first user experience.

---

## نظرة عامة | Overview

BlueMax ERP is a desktop business-management system designed for manufacturing companies. It combines day-to-day factory operations with back-office reporting in one controlled environment, and ships with a detailed Arabic user book so new teams can get productive quickly.

The system is delivered as a managed Windows package: a client installer, a server component, and maintenance utilities. This repository is the **public product page** — it contains the documentation and product information only.

## المميزات | Key features

- **واجهة عربية كاملة** — Arabic-first interface for factory teams.
- **مكونات Desktop و Server** — separate desktop client and server components.
- **أدوات صيانة** — maintenance utilities included in the release package.
- **استعادة كلمة مرور المدير** — an administrator recovery flow for locked-out accounts.
- **تقارير وتشغيل يومي** — reporting and daily-operations workflows documented in the user book.
- **ترخيص مرن** — flexible licensing options to match different factory sizes and trial periods.

## التثبيت | Installation

1. Obtain the official installer package from the owner.
2. Take a **verified backup** of your current database before any update.
3. Close BlueMax, then run the installer manually.
4. Select the correct device type (Desktop / Server) when prompted.
5. Follow the release README and the user book for post-install configuration.

> The installer executable is **not** published in this repository. It is distributed privately as part of the licensed release package.
